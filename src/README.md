## 📌 About

Rivo is a responsive fashion landing page developed to practice modern frontend development and utility-first CSS styling.

This project is a separate implementation of the original Rivo website, using Tailwind CSS v4 to create responsive layouts and a clean, modern user interface.

## 🛠️ Technologies

- HTML5
- Tailwind CSS v4
- JavaScript

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and clean UI
- Utility-first styling with Tailwind CSS
- Responsive navigation menu
- Product cards and collections
- Exclusive offer section
- Customer testimonials
- Newsletter subscription form
- Responsive footer

## 📱 Responsive Design

The website adapts to different screen sizes using Tailwind CSS responsive breakpoints:

- Desktop
- Tablet
- Mobile
